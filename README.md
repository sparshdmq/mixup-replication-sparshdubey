Reproducing *MixUp: Beyond Empirical Risk Minimization*

## 📄 Overview
This project reproduces the core findings of the paper:  
> **Zhang, H., Cisse, M., Dauphin, Y. N., & Lopez-Paz, D. (2017).**  
> *MixUp: Beyond Empirical Risk Minimization.*  
> arXiv preprint [arXiv:1710.09412](https://arxiv.org/abs/1710.09412).

The goal of this project is to replicate the **MixUp data augmentation technique** and evaluate its effectiveness on standard image classification datasets.  
This replication study aligns with the principles of **open science** and **reproducible research**, examining whether MixUp improves model generalization and robustness.

---

## 📁 Repository Contents
- `MixUp_Reproduction_with_dataset_figs.ipynb` → Jupyter Notebook containing full replication experiments.
- `Reproducing_MixUp_Data_Augmentation.pdf` → Final report documenting methodology, results, and analysis.
- Figures and model performance visualizations generated during training.

---

## 🧰 Datasets
This project uses two standard datasets:
1. **CIFAR-10** — 60,000 color images across 10 classes.
2. **Fashion-MNIST** — 70,000 grayscale images of clothing categories.
